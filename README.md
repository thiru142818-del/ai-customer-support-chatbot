# AI Customer Support Chatbot Prototype

A simple interactive customer support chatbot prototype built using HTML, CSS, and JavaScript.

## Project Overview

This project demonstrates a basic customer support chat interface that responds to common customer questions about:

- Order tracking
- Returns and refunds
- Delivery information
- Payment methods

The prototype uses predefined, topic-based response logic to demonstrate user input handling and automated support workflows.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Interactive chat interface
- User message handling
- Predefined topic-based responses
- Quick question buttons
- Responsive design for desktop and mobile screens

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Type a question or select one of the quick question buttons.

No additional installation is required.

## Current Limitation

This is a rule-based chatbot prototype. It does not currently connect to a live AI model, IBM watsonx, or an external API.

The project can be extended in the future by integrating an AI model through a backend service and REST API.

## Learning Outcomes

- Building a responsive web interface
- Handling user input with JavaScript
- Implementing basic conditional response logic
- Organizing a small web project into separate files
- Understanding a foundation for future chatbot and API integration
